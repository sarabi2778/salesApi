# Revenue API Server

## Prerequisites

Before running the server, make sure you have the following installed:

- **Node.js** (Version 14 or higher)
- **npm** (Node package manager)

### Install Node.js

Download and install Node.js from [here](https://nodejs.org/).

### Install Dependencies

Once Node.js is installed, clone this repository and install the necessary dependencies:

```bash
git clone https://github.com/your-username/salesApi.git
cd salesApi
npm install
